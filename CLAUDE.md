# Repository notes

## Working branch

All development and pushes for this repository go to the `antivirus` branch.
Do **not** push to `claude/*` branches or create new branches with the
`claude/` prefix. If a task says to work on a different branch, prefer
`antivirus` unless the user explicitly overrides it in the same message.

## Commit authorship

Use a neutral author identity (e.g. `kashwtv <kashwtv@users.noreply.github.com>`)
for commits. Do not include `Claude`, `Anthropic`, `https://claude.ai/code/...`
trailers, `Co-Authored-By: Claude`, or any other AI-assistant attribution in
commit messages or authorship.
